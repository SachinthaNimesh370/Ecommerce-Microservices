# Product Service Development & API Guide

## 1. Overview
The **Product Service** is an independent microservice responsible for managing the product catalog within the E-Commerce architecture. It handles product creation, retrieval, updates, and deletion.

## 2. Architecture & Configuration
*   **Port:** `8082`
*   **Database:** PostgreSQL
*   **Database Name:** `product_db`
*   **Security:** Stateless JWT Authentication. Public access is granted for retrieving products, while modification endpoints require authentication.

## 3. Product Entity Structure
The `Product` entity contains the following fields:
*   `id` (Long) - Primary Key
*   `name` (String)
*   `description` (String)
*   `price` (BigDecimal)
*   `category` (String)
*   `quantity` (Integer)
*   `createdAt` (LocalDateTime) - Auto-generated
*   `updatedAt` (LocalDateTime) - Auto-generated

---

## 4. API Endpoints

> **Note on Authentication:** Endpoints marked as **[Requires Auth]** require a valid JWT token generated by the **user-service**. Include the token in your request headers:
> `Authorization: Bearer <your_jwt_token>`

### 4.1 Create a New Product
*   **Access:** Admin Only **[Requires Auth]**
*   **Method:** `POST`
*   **URL:** `http://localhost:8082/api/products`
*   **Headers:** `Content-Type: application/json`, `Authorization: Bearer <token>`
*   **Sample Request Body:**
```json
{
  "name": "Laptop",
  "description": "Dell XPS 13 Laptop",
  "price": 250000,
  "category": "Electronics",
  "quantity": 20
}
```

### 4.2 Get All Products
*   **Access:** Public
*   **Method:** `GET`
*   **URL:** `http://localhost:8082/api/products`
*   **Headers:** None required.

### 4.3 Get Product by ID
*   **Access:** Public
*   **Method:** `GET`
*   **URL:** `http://localhost:8082/api/products/{id}` *(Replace `{id}` with the actual product ID, e.g., `/api/products/1`)*
*   **Headers:** None required.

### 4.4 Update a Product
*   **Access:** Admin Only **[Requires Auth]**
*   **Method:** `PUT`
*   **URL:** `http://localhost:8082/api/products/{id}`
*   **Headers:** `Content-Type: application/json`, `Authorization: Bearer <token>`
*   **Sample Request Body:**
```json
{
  "name": "Laptop",
  "description": "Dell XPS 13 Laptop - 16GB RAM upgraded",
  "price": 275000,
  "category": "Electronics",
  "quantity": 15
}
```

### 4.5 Delete a Product
*   **Access:** Admin Only **[Requires Auth]**
*   **Method:** `DELETE`
*   **URL:** `http://localhost:8082/api/products/{id}`
*   **Headers:** `Authorization: Bearer <token>`

## 5. Local Testing Workflow (Postman)
1. Start the **user-service** (port `8081`).
2. Start the **product-service** (port `8082`).
3. Send a login/register `POST` request to `http://localhost:8081/api/auth/login` to obtain a JWT token.
4. Copy the JWT token from the response.
5. In Postman, open a new request for the `product-service` (e.g., `POST http://localhost:8082/api/products`).
6. Go to the **Headers** tab, add `Authorization` as the key, and `Bearer <your_copied_token>` as the value.
7. Send the request.
